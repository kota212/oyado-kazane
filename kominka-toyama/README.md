## 紹介文

### キャッチコピー（媒体の見出し欄用）

> 床の間と欄間、黒塗りの格天井。おわらの町・越中八尾に残る日本家屋に、まるごと泊まる。

### 紹介文（標準・約400字）

おわら風の盆で知られる富山市八尾町。その旧町を車で数分に望む福島の集落に、「越中八尾 お宿風音」はあります。床の間と欄間、黒く塗られた格天井をそのまま残した座敷は、いまはもう新しく建てることのできない造り。石張りの玄関で靴を脱ぎ、障子越しのやわらかな光の中、畳にお布団を並べて眠る──日本家屋の暮らしを、ひと晩まるごと体験できる素泊まりの宿です。

お部屋は全部で四室だけ。六名までひと間で泊まれる広い座敷が二室と、三名までの小間が二室。全室にWi-Fi・エアコン・冷蔵庫を備え、浴槽のあるお風呂とお手洗いは共用です。敷地内には無料駐車場があり、おわら風の盆の三日間（毎年9月1〜3日）も交通規制の外側のため、車を停めてそのまま歩いて祭りへ向かえます。

旧町の中に泊まりたい方には、明治十年の町家を使った姉妹店「越中八尾 風の宿」も。ご予約・空室確認は公式LINEにて承ります。

### 紹介文（短縮版・約150字）

床の間と欄間、黒塗りの格天井のある座敷を残した、全4室だけの小さな素泊まり宿。畳にお布団を並べ、六名までひと間で泊まれます。おわら風の盆で知られる越中八尾・旧町へ車で数分、敷地内に無料駐車場。全室Wi-Fi完備。ご予約は公式LINEで。
